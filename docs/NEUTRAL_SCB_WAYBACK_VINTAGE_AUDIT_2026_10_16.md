# SCB exact-vintage archive audit

This step searches the Internet Archive CDX index for archived captures of the exact SCB API/PxWeb table URLs for:

- BE0101J/Flyttningar97
- BE0101A/BefolkningNy
- BO0104D/BO0104T04

Window: February through mid-May 2024.

A capture can establish that a specific table endpoint existed at a date and may preserve table metadata. It **does not by itself certify the exact cell values returned by a historical POST query**. Strict as-of approval still requires either an archived value response, a version-specific source snapshot, or equivalent official revision/version evidence.

No model is fitted and no feature is automatically upgraded to as-of verified.
